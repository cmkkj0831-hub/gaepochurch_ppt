# ⛪ 개포동성당 초등부 미사 PPT 자동 생성

매주 천주교 매일미사 웹사이트에서 전례 정보를 자동으로 파싱하여 초등부 주일학교 미사 PPT를 생성하는 웹앱입니다.

🔗 **앱 접속**: https://gaepochurch-ppt.streamlit.app

---

## 📖 사용 방법

### 매주 순서

#### 1️⃣ PPT 만들기 (월-금)
1. 앱의 **"📝 PPT 만들기"** 탭 접속
2. 기준 PPT 선택 (기본: 최신 최종본)
3. 매일미사 URL 입력 → **[🔄 불러오기]**
   - URL 예: `https://maria.catholic.or.kr/mi_pr/missa/missa.asp?...`
4. 파싱된 정보 확인 및 필요시 수정
   - 표지 제목, 날짜, 독서, 화답송, 복음, 영성체송
5. 성가 번호 입력 (입당, 봉헌, 성체, 파견)
6. **[🚀 PPT 생성]** → 파일 다운로드
7. PowerPoint에서 열어 원하는 대로 다듬기

#### 2️⃣ 최종본 올리기 (금-토 아침)
1. 앱의 **"📤 최종본 올리기"** 탭 접속
2. 다듬은 PPT 파일 업로드
3. 파일명 확인 (자동 인식)
4. 올린 사람 이름 입력 (선택)
5. **[💾 저장]** → GitHub에 자동 저장
6. ✅ 다음 주 기준 PPT로 자동 선택됨

### 성가 관리 (관리자만)

**"🎵 성가 관리"** 탭:
- 관리자 비밀번호 입력
- 등록된 성가 목록 확인
- 새 성가 이미지 업로드
- 성가 삭제

---

## 📋 파일명 규칙

### 최종본 PPT
```
YYMMDD미사.pptx

예: 261017미사.pptx
    ^^: 연도 (26 = 2026)
      ^^: 월 (10 = 10월)
        ^^: 일자 (토요일 기준, 17일)
```

### 성가 이미지
```
{번호}.png  또는  {번호}-{장}.png

예: 58.png       (한 장)
    106-1.png    (여러 장 중 1장)
    106-2.png    (여러 장 중 2장)
```

## 🛠️ 운영 가이드

### 최종본 PPT 정리
- **일자**: 금요일 또는 토요일 아침
- **파일명**: 미사 예정 토요일 기준 (예: 10월 17일 토요일 → 261017미사.pptx)
- **저장**: 앱에서 자동으로 GitHub에 저장됨

### 성가 이미지 추가
1. 앱의 **성가 관리** 탭에서 관리자 비밀번호 입력
2. 새 성가 이미지 여러 개 업로드
3. 파일명 규칙: `58-1.png`, `106.jpg` 등
4. **[📤 업로드]** → 자동 저장

### 문제 해결

**Q: 앱이 열리지 않아요**
- Streamlit Community Cloud 프리 티어는 잠시 사용이 없으면 슬립 상태가 됩니다
- 링크를 다시 열면 자동으로 깨어납니다 (30초-1분 소요)

**Q: 매일미사 URL을 어디서 구하나요?**
- https://maria.catholic.or.kr 접속 → 원하는 주일 미사 선택 → 주소창 URL 복사

**Q: 최종본 파일명이 자동 인식 안 돼요**
- 표지 슬라이드의 날짜 형식 확인 (예: 2026.10.17)
- 파일명을 수동으로 수정 가능합니다

**Q: GitHub에 올라간 파일이 보이지 않아요**
- 앱에서 캐시를 사용합니다
- 새로고침 또는 앱 재접속하면 반영됩니다

## 💻 로컬 개발 (개발자용)

### 설치
```bash
git clone https://github.com/cmkkj0831-hub/gaepochurch_ppt.git
cd gaepochurch_ppt
pip install -r requirements.txt
```

### 로컬 secrets 설정
```bash
# .streamlit/secrets.toml 생성
cat > .streamlit/secrets.toml << 'EOF'
GITHUB_TOKEN = "github_pat_..."
GITHUB_REPO = "cmkkj0831-hub/gaepochurch_ppt"
GITHUB_BRANCH = "main"
ADMIN_PASSWORD = "your_password"
EOF
```

### 앱 실행
```bash
streamlit run app.py
```
